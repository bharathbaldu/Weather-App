# Weather App

A beginner-friendly weather application built with HTML, CSS, and JavaScript. It searches for a city and displays current temperature, feels-like temperature, humidity, wind speed, and a weather description.

## Features
- Search weather by city name
- Live current weather data
- Loading and error messages
- Responsive layout for mobile and desktop
- No API key required (uses Open-Meteo public APIs)

## Technologies
- HTML5
- CSS3
- JavaScript (Fetch API, async/await)
- Open-Meteo Geocoding API and Forecast API

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a browser.
3. Enter a city name, such as Hyderabad, and click **Search**.
4. An internet connection is required to retrieve live weather data.

## Files
- `index.html` — page structure
- `style.css` — styling and responsive layout
- `script.js` — city lookup and weather API requests

## Learning notes
This project demonstrates DOM selection, form events, input validation, `fetch()`, JSON responses, `async/await`, and error handling.

## API
Weather data is provided by Open-Meteo: https://open-meteo.com/
